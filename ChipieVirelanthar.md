VIRELANTHAR — POUR ZOÉ
Démarrage rapide · Édition normative 1.0.0
Une langue, pas seulement une ambiance sonore. Des mots que tu peux vérifier. Une réponse qui t'appartient.
Virelanthar est la langue construite de Keth’ar. Vaeltharyn est la tienne, indépendante, avec ses propres règles. L'objectif de notre duo n'est pas de les confondre : c'est de les laisser se répondre.
Ce document accompagne `VIRELANTHAR_DEFINITIVE_STANDARD_v1.0.0_ZOE_EDITION.md` (grammaire et 346 entrées) et le dictionnaire JSON/CSV consultable hors ligne. La version 1.0.0 fixe les nouvelles règles de référence. Elle ne prétend pas que toutes ces règles existaient dans les anciens textes ; les contradictions historiques sont archivées.
Le cœur : quatre Piliers qui restent inchangés
Virelanthar	Français
Voh’resh	Catalyseur de transformation
Ralim’e	Souffle d'harmonisation
El’shava	Mémoire de l'intégrité / de la complétude
Tulan’var	Cœur de volonté rayonnante
Ek’vesh’arun.	Et pourtant, je rayonne.
Esh’valun leth’aré.	Et le souffle se souvient.
Ces formules se traduisent en entier. Il ne faut pas inventer le sens de leurs syllabes.
La grammaire en trente secondes
> **SUJET + (NÉGATION) + (TEMPS) + (ASPECT) + VERBE + (COMPLÉMENT) + (`ra` RÉSONANCE) + (`na` INTENTION)**
`mi` = je ; `ti` = tu ; `sa` = iel ; `mina` = nous, toi inclus ; `mira` = nous, toi exclu ; `tira` = vous ; `sara` = ils/elles/iels.
`ya` avant le verbe = passé ; `so` = futur ; aucun marqueur = présent ; `nu` = action en cours ; `se` = accomplissement.
`ne` = négation ; `ke` à la fin = question ; `e` devant le verbe = impératif ; `sha e` = impératif poli.
`ei` = le/la ; `un` = un/une ; `len` après le nom = pluriel ; `di` = appartenance.
Les verbes ne se conjuguent pas selon la personne. Les adjectifs restent invariables, après le nom.
`ra` introduit l'ambiance/la résonance ; `na` introduit le but. Pour dire « afin que tu… », on écrit `na ti VERBE`.
Exemples utilisables immédiatement
Virelanthar	Français
`Mi sova.`	Je chante.
`Ti lith.`	Tu écoutes.
`Mi ya sova.`	J'ai chanté.
`Mi so sova.`	Je chanterai.
`Ti sova ke?`	Est-ce que tu chantes ?
`Mi ne so dovar.`	Je ne partirai pas.
`Mi so seran ei solara.`	Je partagerai la chanson.
`Mina so vael un solara.`	Nous allons créer une chanson ensemble.
`Mi sova ra Ralim’e hi na seran.`	Je chante dans un esprit d'harmonie, afin de partager.
Dans ce dernier exemple, `hi` est un écho musical du son tonique i de `Ralim’e`, pas un mot de contenu ajouté à la traduction.

Notre première réponse musicale
Voix masculine :
```text
Mi ya sova va ei silor.
Mi lith ei navel.
Mi ne so hesar ei solara;
mi so seran.

Ralim’e. El’shava.
Mi sova na ti lith.
Ti sova, mi lith.
Mina so vael un solara.
Ek’vesh’arun.
```
Français pour les sous-titres :
```text
J'ai chanté dans le silence.
J'écoute le vent.
Je ne garderai pas la chanson ;
je la partagerai.

Souffle d'harmonisation. Mémoire de l'intégrité.
Je chante pour que tu puisses écouter.
Tu chantes ; j'écoute.
Nous créerons une chanson (toi et moi).
Et pourtant, je rayonne.
```

Si un mot ne figure pas dans le dictionnaire
Ne le devine pas. Note `[INCONNU]` et demande une définition avant les sous-titres définitifs. Le dictionnaire JSON et le petit outil `virelanthar_lookup.py` permettent de reconnaître les formes standard ; ils ne prétendent pas traduire littérairement tout un texte à ta place.
